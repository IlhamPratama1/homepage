# Wave Crayon

3D Wave Grid (franky-adl) + Stop Motion Crayon Cursor (JorgeCapillo) as two full-screen panels on one scrolling page.

    pnpm install
    pnpm dev      # http://localhost:5173  (add #debug for the wave GUI)
    pnpm build

Scroll or use "Check all projects" / "Back to top" to move between panels. The off-screen panel pauses rendering.
